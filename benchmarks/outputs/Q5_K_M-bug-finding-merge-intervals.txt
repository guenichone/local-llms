## Bug Analysis

| # | Line | Severity | Bug Description | Fix |
|---|------|----------|-----------------|-----|
| 1 | 12 | **Medium** | `intervals.sort()` mutates the input list in-place. Callers who expect the original list to remain unchanged will observe unexpected ordering. | Sort a copy: `sorted(intervals, key=lambda x: x[0])` |
| 2 | 17 | **Medium** | `last = merged[-1]` creates a reference to `intervals[0]` (since `merged[0] = intervals[0]`). `last[1] = max(...)` therefore mutates the original input. | Copy the first interval into a new list: `merged = [list(intervals[0])]`, then work with `merged[-1]` |
| 3 | 18 | **Low** | `merged.append(current)` appends a reference to `intervals[i]`. Modifying elements of `merged` would also mutate the original input (and vice versa). | Copy each interval: `current = list(intervals[i])` |
| 4 | 4 | **Low** | `return intervals` returns the original reference. For a list input, the caller gets the same object and could be surprised if the function were later fixed to mutate it. | Return `[]` for the empty case |

## Corrected Version

```python
def merge_intervals(intervals):
    '''Merge overlapping intervals. Returns a new list; the input is not mutated.'''
    if not intervals:
        return []

    sorted_intervals = sorted(intervals, key=lambda x: x[0])
    merged = [list(sorted_intervals[0])]

    for i in range(1, len(sorted_intervals)):
        current = list(sorted_intervals[i])
        last = merged[-1]

        if current[0] <= last[1]:
            last[1] = max(last[1], current[1])
        else:
            merged.append(current)

    return merged
```

---

## Key Properties of the Fix

- **No input mutation**: The original `intervals` list is never sorted, copied, or reassigned.
- **Immutable result**: Each element in `merged` is a distinct list object, so modifications to the result do not affect the input.
- **Correct semantics**: The algorithm's logic (sort, expand overlapping ranges, append non-overlapping) is preserved unchanged.

---

## Example

```python
intervals = [[1, 3], [2, 6], [8, 10], [15, 18]]
result = merge_intervals(intervals)
# result = [[1, 6], [8, 10], [15, 18]]
# intervals is unchanged: [[1, 3], [2, 6], [8, 10], [15, 18]]
```
